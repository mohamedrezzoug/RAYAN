عالم ريان — تطبيق تعليمي للأطفال (PWA) | Le monde de Rayan

للتثبيت على الهاتف واللوحة والحاسوب:
1) أنشئ مستودعًا جديدًا على GitHub (مثلًا rayan) وارفع إليه كل هذه الملفات كما هي (مع المجلدين fonts و icons).
2) Settings > Pages > Branch: main / root > Save.
3) افتح الرابط: https://USERNAME.github.io/rayan/
4) أندرويد (Chrome): القائمة ⋮ > Installer l'application
   آيفون/آيباد (Safari): زر المشاركة > Sur l'écran d'accueil
   الحاسوب (Chrome/Edge): أيقونة التثبيت في شريط العنوان
بعد الفتح الأول، يعمل التطبيق دون إنترنت.
